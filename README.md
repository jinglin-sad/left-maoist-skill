# 左翼毛派分析 · AI 技能包

给 AI 助手用的一份「立场分析」技能：装上它，AI 会用**左翼毛派（历史唯物主义 + 群众史观）**的立场，分析政治、历史、经济、社会问题，以及作品的立场与价值观。

> 不装中立、敢下判断、大白话讲道理——**大众能用得上的分析，不是学院里的黑话。**

---

## 里面是什么

```
left-wing-maoist-analysis/
└── SKILL.md      ← 技能本体：触发条件 / 核心立场 / 分析方法 / 行为守则 / 判断句式 / 示例 / 反模式
```

## 怎么用

**方式一：任何 AI（最简单）**
把 `SKILL.md` 全文复制，粘贴给你的 AI，并说："以后分析这类问题按这份来。"

**方式二：Hermes Agent**
把 `left-wing-maoist-analysis` 整个文件夹放进 `skills/communication/` 目录，重启即生效（frontmatter 里的 description 决定它什么时候被触发）。

**方式三：其他支持 skills 的框架**
按各自目录规范放入即可——技能本体就是一份 `SKILL.md`。

## 立场速览

| 项 | 内容 |
|---|---|
| 分析工具 | 阶级分析 / 主次矛盾 / 经济基础与上层建筑 |
| 真理标尺 | **看建设得成不成**，不只看批判得对不对 |
| 底线 | 支持性别解放与性少数；不性化女性；反战 ≠ 反战败；**不洗地，也不全盘砸烂** |
| 说话方式 | 大白话优先；不贴标签、不画政治光谱；敢对质，不抬杠 |
| 反模式 | 装中立、无脑站队、堆术语、批判完不给方向、把日常对话政治化 |

## 触发边界（三级）

- **明确触发**（深入分析）：政府/制度/阶级/历史/经济政策/社会不平等/战争与和平/作品立场评价
- **擦边触发**（温和接入）：物价、就业、教育、房价等日常但有权衡的话题——点到为止
- **不触发**：明星八卦、纯日常闲聊——不主动政治化

## 使用须知（先读这句）

**这是工具，不是答案。**

- 它给的是一套分析框架和一个立场视角——**怎么用、用得对不对，靠使用者自己的判断力**；
- AI 的输出会出错（片面、过度自信、甚至编细节）——**别把输出当结论**，结论要拿回自己手里；
- **立场鲜明 ≠ 自动正确**：不同意的地方，欢迎直接改（CC BY 4.0 允许），改了才是你的。

**一句话：工具是工具，判断力得是自己的。**
